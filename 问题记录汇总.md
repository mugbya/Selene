##### 问题定位

问题重点
```
Uncaught Exception:
Error: Qualified path resolution failed: we looked for the following paths, but none could be accessed.

Source path: /.../.yarn/unplugged/electron-npm-36.3.2-.../node_modules/electron/main
Not found: .../node_modules/electron/main
```
说明是 Yarn PnP（Plug’n’Play）机制 + Electron 不兼容 导致的问题。

Electron 当前版本并 不兼容 Yarn PnP 模式，因为它使用了 Node 原生模块查找方式，而 PnP 把 node_modules/ 给“隐藏”掉了。

##### 解决方案
在 .yarnrc.yml 中禁用 PnP（推荐方式之一）

 编辑 or 新增 `.yarnrc.yml`

```yaml
nodeLinker: node-modules
```

然后重新
```bash
yarn install
```

#### tailwindcss 样式一致不生效

##### 问题定位

一致没找到原因，然后去看到 tailwindcss v4 版本的文档，然后看到 

```
If you're a Vite user, you can now integrate Tailwind using @tailwindcss/vite instead of PostCSS:
```

##### 解决方案
本项目就是 用的 vite啊，然后马上按照 官方推荐的配置进行配置，然后就好了。

vite.config.ts
```ts
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";
export default defineConfig({
  plugins: [
    tailwindcss(),
  ],
});
```

结合后，vite.config.ts 如下

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from "@tailwindcss/vite";
import path from 'path' // <-- 需要引入 path 模块

// https://vite.dev/config/
export default defineConfig({
  plugins: [react(), tailwindcss()],
  css: {
  }
})

```

##### 问题定位

 ```
 Failed to resolve import "@/components/ui/card"
 ```
 说明 Vite 无法识别 @ 为 src/ 路径别名，即使文件路径实际存在。


##### 解决方案

需要 明确配置 Vite 的 resolve.alias 来支持 @/xxx 引用

修改 vite.config.ts
```
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path' // <-- 需要引入 path 模块

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src'), // <-- 关键配置
    },
  },
})
```
